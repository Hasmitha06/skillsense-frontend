# SkillSense AI — Frontend

React dashboard and guided assessment workflow for SkillSense AI, now wired
up to the real FastAPI backend (see the `skillsense-backend` project) —
no more mock data.

## Setup

1. Make sure the backend is running first (see its own README):
   ```bash
   uvicorn app.main:app --reload
   ```
   It should be live at `http://localhost:8000`.

2. Then, in this project:
   ```bash
   npm install
   npm run dev
   ```
   Open the local URL Vite prints (usually `http://localhost:5173`).

Optional: copy `.env.example` to `.env` if your backend runs somewhere other
than `http://localhost:8000` (edit `VITE_API_BASE`).

## What's wired up

- **Auth**: real signup/login against `/auth/signup` and `/auth/login`,
  JWT stored in `localStorage`, session restored on page refresh via
  `/auth/me`.
- **Roles & questions**: fetched live from `/roles` and
  `/assessment/questions`.
- **AI evaluation**: submitting the quiz calls `/assessment/submit`; the
  real rule-based result (skills, strengths, gaps, readiness,
  recommendation, roadmap) flows into every later step.
- **Retest**: re-answers the same questions and resubmits, creating a
  second assessment attempt.
- **Progress comparison**: fetched from `/progress` — compares your last
  two attempts for the role.
- **Reports**: the PDF and Excel buttons in the final step download real
  files generated by the backend (`reportlab` / `openpyxl`).

## Troubleshooting

- **"Failed to fetch" / network errors**: the backend isn't running, or
  `VITE_API_BASE` doesn't match where it's running.
- **CORS errors in the browser console**: the backend's `CORS_ORIGINS` in
  its `.env` doesn't include your frontend's origin (default
  `http://localhost:5173` — already the default on both sides).
- **401 errors after a while**: your token expired (default 24h) — just
  log in again.
